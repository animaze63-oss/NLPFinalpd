# Licensing and attribution

- RT Kaggle dataset: declared **CC0** by the uploader. The review text itself was written by critics and publishers, so the app shows **short excerpts with `critic_name` and `publisher_name`** and links to Rotten Tomatoes. Never present excerpts as our own writing.
- IMDb non-commercial data: personal and non-commercial use only (https://developer.imdb.com/non-commercial-datasets/). OK for a class project as a filter; don't redistribute the raw files.
- IMDb review corpus: cite Maas et al. (2011).
- Record in `data/README.md`: source URL, dataset version, download date, filters applied, row counts before/after, licence notes.
