# Build settings

Source: https://docs.netlify.com/build/configure-builds/overview/

- **Base directory**: "directory where Netlify checks for dependency management files… installs dependencies, and runs your build command. The build system will use this directory to perform caching during the build process. If not set, the base directory defaults to the root of the repository."
- **Build command**: "The build command runs in the Bash shell, allowing you to add Bash-compatible syntax to the command." (`&&` chains are fine.)
- **Publish directory**: "directory that contains the deploy-ready HTML files and assets generated by the build… relative to the base directory."
- **Build image selection**: Project configuration › Developer settings › Continuous deployment › Build image selection. Applies to production deploys, branch deploys and Deploy Previews. Netlify recommends upgrading to the newest image regularly.
- **Build time limit**: not confirmed in these pages. Commonly 15 minutes by default; check the team's plan in the UI before the first long build.

Project: base = repo root, command = NLTK data download + `python pipeline/build_data.py`, publish = `site`.
