# Static site layout (no server, no framework requirement)

```
site/
  index.html            # shell: header, film picker, dashboard sections, analyzer panel
  css/styles.css        # tokens (light/dark), layout, components
  js/app.js             # routing (/film/<slug> via history API + Netlify 200 rewrite), fetch, render
  js/charts.js          # Chart.js wrappers + data tables
  js/analyzer.js        # lazy-creates the Pyodide worker (owned by PYO)
  vendor/               # pinned third-party JS (Chart.js)
  data/                 # generated by the pipeline (never hand-edit)
  pyodide/ nltk_data/ py/   # PYO assets
```
- Read only fields defined in the data contract; tolerate missing optional fields.
- Mobile first: 16 px side gutter, no horizontal scroll at 360 px.
- Sections per film: header (title, year, director, tomatometer, consensus), overall gauge, aspect cards (visuals/story/characters/soundtrack with score, top opinion words, 2 quotes), praise vs criticism words, collocations, people & comparisons (entities), timeline, methodology link.
