NLTK runs in your browser (Pyodide)

🔒Your text never leaves this device. Python and NLTK run in a Web Worker in your browser with Pyodide. Nothing is uploaded, stored or sent to a server. The first run downloads about 14 MB from this site (the Python runtime plus NLTK).

Write in English, up to 5,000 characters. Scored with NLTK VADER, using the same sci-fi lexicon rules as the dashboard.

spaCy cannot run in the browser (it is not available in Pyodide), so aspects here are found with the shared keyword list. The film dashboards use spaCy dependency parses computed at build time.
