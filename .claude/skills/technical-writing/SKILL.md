# technical-writing

Used by: **nlp-evaluator** (owner), orchestrator, meta-agent, nltk-expert, spacy-expert, pipeline-engineer, netlify-engineer

- Lead with the answer; one idea per paragraph; plain words; define NLP terms once.
- Every fact that came from outside has a link; every number says where it came from (file, build, date).
- Docs live in `docs/`; per-folder READMEs explain how to run that part.
- Methodology text must state what was measured, the numbers, and known failure modes.
