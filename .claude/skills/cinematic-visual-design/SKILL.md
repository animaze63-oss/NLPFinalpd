# cinematic-visual-design

Used by: **ux-designer** (owner), frontend-engineer

- Dark-first theater palette + full light theme; one accent; letterboxed film hero.
- Order: identity → verdict → four aspect "reels" → evidence → methodology.
- Diverging −1…+1 sentiment scale with a neutral midpoint; colour-blind-safe blue ↔ orange; never colour alone.
- Deliver tokens as CSS custom properties, wireframes for 360 px and desktop, and copy for loading/empty/error states.
